🎮 Steam Lua API

Download Steam depot Lua scripts via a simple REST API

https://steamluas.vercel.app/api/
✅ API Online 🌐 CORS Enabled

📖 Overview

This API provides programmatic access to 66,000+ Lua files used for Steam depot installations. Files are fetched from GitHub and served via a simple REST interface.


Data Source: thecloudyy/lua-database

Total Files: 66,481+

🔗 Endpoints

1. Download Lua File

Retrieve a Lua file by its Steam AppID.

GET /download/{appid} Path parameter
GET /download?appid={appid} Query parameter
ParameterTypeDescription
appidintegerSteam AppID (e.g., 440)

2. List All AppIDs

Get a complete list of all available AppIDs.

GET /list Returns JSON

📝 Usage Examples

cURL

# Download Lua file
curl -O https://steamluas.vercel.app/api/download/440

# List all AppIDs
curl https://steamluas.vercel.app/api/list

Python

import requests

# Download
response = requests.get('https://steamluas.vercel.app/api/download/440')
print(response.text)

# List
response = requests.get('https://steamluas.vercel.app/api/list')
data = response.json()
print(data['count'], 'files available')

JavaScript

// Download
fetch('https://steamluas.vercel.app/api/download/440')
.then(res => res.text())
.then(data => console.log(data));

// List
fetch('https://steamluas.vercel.app/api/list')
.then(res => res.json())
.then(data => console.log(data.appids));
